# Zee private field study

This directory preserves the interactive human-interaction study that was
previously published through the Observatory routes:

- `/travellers/zee/`
- `/archive/`
- `/chapter/[slug]/`

The study includes Zee's working instruments, encounters, field analysis,
private-device notes, findings, chapter registry, and its former shared chrome.

It was removed from `src/` on 2026-08-20 because this material belongs to
Zee's private working environment and is not part of the public Observatory
case study. Keeping it here preserves the experiment without exposing it in
the production build.

The source tree retains its original SvelteKit layout and import paths as a
snapshot. It is not currently a standalone application.

Public Zee material now belongs to the Observatory case-study surface at:

`/case-studies/zee/`
